Email Spam Detection
Project Overview
This project uses Machine Learning to classify emails into two categories: Spam and Not Spam.

Technologies Used
Python
Pandas
NumPy
Scikit-learn
NLP
Jupyter Notebook

Project Workflow
Loaded and explored the email dataset.
Cleaned and preprocessed email text.
Converted text into numerical features using TF-IDF.
Trained Naive Bayes and Logistic Regression models.
Evaluated models using accuracy and classification reports.
Results

Compared both models to identify the best-performing classifier for spam detection.
Conclusion
This project demonstrates how Machine Learning can automatically identify spam emails and distinguish them from legitimate messages.
