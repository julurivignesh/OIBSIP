#Task 2 - Unemployment Analysis with python
  ##Objective
  performed exploratory data analysis on unemployment data in India,focusing on the impact of COVID-19 on unemployment rates across states 
  ##Tech Stack
  Python,pandas,matplotlib,seaborn,Jupyter Notebook
  ##Key Findings
    -Average unemployment rate nearly doubled post-COVID(9.51% to 17,77%)
    -Tripura and Haryana had the highest average unemployment rates 
    -April 2020 saw a sharp spike to 23.64%,following the COVID-19 lockdown
