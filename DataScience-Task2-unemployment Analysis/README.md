Unemployment Analysis

Project Overview

This project analyzes unemployment data to understand changes in unemployment rates across different regions and over time.

Objectives

- Explore the dataset and check for missing values.
- Analyze unemployment trends over time.
- Compare unemployment rates across states or regions.
- Study changes before and after COVID-19.
- Visualize the results using charts.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
